# PBRStudio Special Example Sources

The downloaded example textures in this folder are from ambientCG.

ambientCG assets are provided under the Creative Commons CC0 1.0 Universal license:
https://ambientcg.com/license/

Downloaded asset sets:

- `LeafSet030_1K-JPG` - leaf atlas for two sided foliage examples.
- `AsphaltDamage001_1K-JPG` - damage/decal texture for DBuffer decal examples.
- `Fence007A_1K-JPG` - fence/mesh texture for window screen examples.
- `Fabric080_1K-JPG` - fabric texture for lampshade examples.
- `Metal032_1K-JPG` - metal texture for car paint / clear coat examples.

The plugin prefers these files for special material demo textures and falls back to generated placeholder textures only when a downloaded source is unavailable.
