# Paint Example Texture Sources

The paint example textures in this folder are from ambientCG.

ambientCG assets are provided under the Creative Commons CC0 1.0 Universal license:
https://ambientcg.com/license/

Downloaded asset sets:

- `LatexPaint` uses ambientCG `Plaster002_1K-JPG` for a clean rough white plaster / latex paint wall example.
- `Microcement` uses ambientCG `Concrete016_1K-JPG` for a smooth grey concrete / microcement example.

Only the image maps needed by the UE examples are kept here: base color, DirectX normal, roughness, height, and preview image.
